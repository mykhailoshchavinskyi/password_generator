# Passgen

[![CI](https://github.com/mykhailoshchavinskyi/password_generator/actions/workflows/ci.yml/badge.svg)](https://github.com/mykhailoshchavinskyi/password_generator/actions/workflows/ci.yml)

Десктопний генератор парольних фраз для Windows, macOS і Linux. Фраза складається з англійських слів, цифр і спецсимволів, наприклад `&!519Deck_449Lip&_867$Wine`. Передрукувати її легше, ніж випадковий набір символів, а стійкість висока: близько 91 біта за стандартних налаштувань.

<img src="docs/images/main-window.png" alt="Головне вікно Passgen" width="460">

- Усі фрази, що відповідають налаштуванням, рівноймовірні. Використовується криптографічно стійкий генератор (`secrets`).
- Можна задати довжину пароля: до N, рівно N або від–до. У двох останніх режимах кількість слів, цифр і символів підбирається автоматично.
- Цифри й символи можна розкидати по частині (`!Deck4#9`) або ставити групами.
- Додаткові ускладнення: велика літера у випадковому місці слова (`blAnket`) і leet-заміни всередині слова (`Bl@nk3t`).
- Режим «без схожих символів»: без 0, 1, `|` і без пари I/l.
- Можна змінювати кількість слів, кількість літер у слові (рівно N або від–до), кількість цифр і символів, набір спецсимволів, роздільник, регістр і словник.
- Шкала показує стійкість у бітах.
- Буфер обміну автоматично очищається, а фраза позначається як секретна для менеджерів буфера.
- Програма працює без інтернету і ніде не зберігає паролі.

## Завантаження

Готові файли для кожної ОС лежать на сторінці [Releases](https://github.com/mykhailoshchavinskyi/password_generator/releases/latest). Як встановити й користуватися, описано в **[посібнику користувача](docs/user-guide.md)**.

## Запуск з вихідного коду

Потрібен Python 3.10+.

```sh
git clone https://github.com/mykhailoshchavinskyi/password_generator.git
cd password_generator
python -m venv .venv && . .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -e ".[dev]"

passgen                  # вікно
passgen-cli -n 5         # консольний режим, сумісний із початковим passgen.py
```

### Алгоритм

Основу алгоритму перенесено з початкового `passgen.py`:

1. Кожна частина фрази — це слово, цифри та спецсимволи. У режимі групами — блок цифр і блок символів у випадковому порядку, як в оригіналі. У режимі розкидання кожна цифра й символ стоять у випадковому місці; кількість розташувань дорівнює (1+цифр+символів)! / (цифр!·символів!).
2. Динамічне програмування (`Generator._exact`) рахує, скільки існує способів заповнити k частин рівно t символами. Звідси кількість фраз для кожної кількості слів у межах `min_len..max_len`.
3. Кількість слів (у режимі `auto_words`), сумарна довжина і довжина кожної частини вибираються пропорційно цим кількостям. Тому всі допустимі фрази рівноймовірні, а `entropy_bits()` дає точну оцінку.

Відмінності від оригіналу:

- усі константи стали параметрами `Config`;
- за замовчуванням 3 слова (в оригіналі `WORDS_COUNT = 1`, тобто ~30 біт);
- блоки цифр і символів можуть бути порожніми, і вага перестановок для них рахується правильно;
- цифри й символи можна розкидати по частині;
- можна задати точну довжину або діапазон довжини пароля з автоматичним вибором кількості слів;
- словник об'єднано з EFF Large Wordlist (9904 слова) і очищено від образливих чи чутливих слів, власних назв і вигуків; джерела — у `src/passgen/data/WORDS-SOURCES.md`;
- велика літера у випадковому місці та leet-заміни; для кожного слова рахується точна кількість написань, тож оцінка лишається точною.

Тест `test_entropy_matches_original_script` перевіряє, що на словнику оригіналу в режимі групами (`scatter=False`, `passgen-cli --grouped`) оцінки збігаються до 1e-9.

## CI і релізи

- **CI** (`.github/workflows/ci.yml`) запускається на кожен push і pull request: ruff, потім pytest на Windows, macOS і Linux з Python 3.10–3.13. Linux-збірка з Python 3.13 також генерує скріншоти й додає їх до запуску як артефакт.
- **Release** (`.github/workflows/release.yml`) запускається за тегом `v*`. Він збирає PyInstaller-ом `.exe` для Windows, `.dmg` для macOS (arm64 і x64), а також `.AppImage` і `.tar.gz` для Linux. Кожен файл запускається в режимі самоперевірки (`PASSGEN_SMOKE_TEST=1`). Потім створюється GitHub Release з файлами і `SHA256SUMS.txt`. Ручний запуск (Actions → Release → Run workflow) з порожнім полем `tag` лише збирає файли; якщо вказати `tag`, наприклад `v1.1.0`, workflow сам створить цей тег на вибраній гілці й опублікує реліз.

Як випустити нову версію:

1. Змініть `__version__` у `src/passgen/__init__.py` і додайте запис у `CHANGELOG.md`.
2. Закомітьте зміни, потім `git tag v1.1.0 && git push origin v1.1.0` (або ручний запуск Release з `tag: v1.1.0`).

Локальна збірка для поточної ОС: `pip install -e ".[build]" && python scripts/build.py`. Результат з'явиться в `release/`.
